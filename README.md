# Predictor Bot

Telegram bot + Mini App для прогнозов на спорт: футбол, хоккей/NHL, теннис, AI-линия, ставки баллами, баланс, P/L, промокоды, ранги, лидерборды, backtest и админ-контроль провайдеров.

## Что уже есть

- Mini App как основной интерфейс: матчи, ставки, профиль, лидерборды, backtest AI-линии.
- Ставки баллами на прогноз: пользователь выбирает исход и сумму, баланс списывается сразу, выигрыш начисляется после результата.
- История ставок и P/L: в профиле Mini App показываются ROI, прибыль/убыток, выигранные ставки и история прогнозов с результатом.
- Ранги: Новичок, Скаут, Аналитик, Профи, Легенда. Ранг зависит от очков и количества прогнозов.
- Промокоды: админ создаёт код, пользователь активирует его в Mini App или командой `/promo CODE`.
- AI/ELO-линия: вероятности и коэффициенты считаются автоматически.
- Provider Health: админ видит, какие источники данных работают, где 0 матчей, где ошибка или rate limit.
- Сезоны: отдельный сезонный лидерборд поверх общего счёта.
- Рефералы: команда `/ref` и ссылка `startapp=ref_<user_id>`, бонусы баллами за приглашение.
- Render-ready запуск через `runner.py`.

## Render ENV

Обязательные:

```env
BOT_TOKEN=...
ADMIN_ID=123456789
PORT=10000
RENDER_EXTERNAL_URL=https://your-service.onrender.com
BOT_USERNAME=your_bot_username
```

Матчи и спорт:

```env
FOOTBALL_ENABLED=1
THESPORTSDB_ENABLED=1
THESPORTSDB_API_KEY=...
SYNC_LOOKAHEAD_DAYS=10
SYNC_INTERVAL=3600
NHL_ENABLED=1
TENNIS_ENABLED=1
TENNIS_TOURS=atp,wta
```

Публичный ключ TheSportsDB `123` сильно лимитируется и часто даёт HTTP 429. Для нормальной продажи и стабильного футбола лучше поставить личный `THESPORTSDB_API_KEY`.

Ставки и баланс:

```env
BETTING_ENABLED=1
MINI_APP_START_BALANCE=1000
MINI_APP_STAKE_PRESETS=50,100,200,500,1000
MINI_APP_MAX_STAKE=100000
REFERRAL_BONUS=250
REFERRAL_REFEREE_BONUS=100
```

Коэффициенты:

```env
ODDS_API_KEY=...
ODDS_REGIONS=eu
ODDS_MARKETS=h2h
ODDS_REFRESH_INTERVAL=900
```

`ODDS_API_KEY` опционален. Без него бот работает на AI/ELO-линии, но для коммерческой версии реальная букмекерская линия повышает ценность.

## Команды

Пользовательские:

- `/start` - старт бота.
- `/app` - открыть Mini App.
- `/ref` - реферальная ссылка.
- `/promo CODE` - активировать промокод.
- `/rank` - посмотреть свой ранг и P/L.

Админские:

- `/admin` - админ-панель.
- `/provider_health` - состояние провайдеров.
- `/sync_now` - ручная синхронизация матчей.
- `/odds_now` - информация по линии.
- `/promo CODE AMOUNT [MAX_USES]` - создать или обновить промокод, например `/promo START500 500 100`.
- `/promos` - список последних промокодов.

## Как проверить после деплоя

1. Render должен стартовать без `TelegramConflictError`.
2. В логах должны появиться `GROWTH_FEATURES_V1_APPLIED` и `RUNNER_GROWTH_FEATURES_APPLIED`.
3. Создай промокод: `/promo TEST500 500 10`.
4. Открой Mini App через Telegram, зайди в профиль и активируй `TEST500`.
5. В профиле должны появиться ранг, P/L, ROI, ставки и блок промокода.
6. В разделе “Мои” история прогнозов должна показывать сумму, коэффициент и прибыль/убыток после закрытия матча.
