# Predictor Bot

Telegram bot + Mini App для прогнозов на спорт: футбол, хоккей/NHL, теннис, AI-линия, ставки баллами, баланс, лидерборды, backtest и админ-контроль провайдеров.

## Что уже есть

- Mini App как основной интерфейс: матчи, ставки, профиль, лидерборды, backtest AI-линии.
- Ставки баллами на прогноз: пользователь выбирает исход и сумму, баланс списывается сразу, выигрыш начисляется после результата.
- AI/ELO-линия: вероятности и коэффициенты считаются автоматически, Mini App показывает AI-пик и причины.
- Provider Health: админ видит, какие источники данных работают, где 0 матчей, где ошибка или rate limit.
- Сезоны: отдельный сезонный лидерборд поверх общего счёта.
- Рефералы: команда `/ref` и ссылка `startapp=ref_<user_id>`, бонусы баллами за приглашение.
- Render-ready запуск через `runner.py`.

## Render ENV

Обязательные:

```env
BOT_TOKEN=...
ADMIN_ID=123456789
PORT=10000
RENDER_EXTERNAL_URL=https://your-service.onrender.com
BOT_USERNAME=your_bot_username
```

Матчи и спорт:

```env
FOOTBALL_ENABLED=1
THESPORTSDB_ENABLED=1
THESPORTSDB_API_KEY=...
SYNC_LOOKAHEAD_DAYS=10
SYNC_INTERVAL=3600
NHL_ENABLED=1
TENNIS_ENABLED=1
TENNIS_TOURS=atp,wta
```

Важно: публичный ключ TheSportsDB `123` сильно лимитируется и часто даёт HTTP 429. Для нормальной продажи и стабильного футбола лучше поставить личный `THESPORTSDB_API_KEY`. `THESPORTSDB_DAY_SEARCH=1` включай только с личным ключом.

Ставки и баланс:

```env
BETTING_ENABLED=1
MINI_APP_START_BALANCE=1000
MINI_APP_STAKE_PRESETS=50,100,200,500,1000
MINI_APP_MAX_STAKE=100000
REFERRAL_BONUS=250
REFERRAL_REFEREE_BONUS=100
```

Коэффициенты:

```env
ODDS_API_KEY=...
ODDS_REGIONS=eu
ODDS_MARKETS=h2h
ODDS_REFRESH_INTERVAL=900
```

`ODDS_API_KEY` опционален. Без него бот работает на AI/ELO-линии, но для коммерческой версии реальная букмекерская линия повышает ценность.

## Команды

Пользовательские:

- `/start` - старт бота.
- `/app` - открыть Mini App.
- `/ref` - реферальная ссылка.

Админские:

- `/admin` - админ-панель.
- `/provider_health` - состояние провайдеров.
- `/sync_now` - ручная синхронизация матчей.
- `/odds_now` - информация по линии.

## Как проверить после деплоя

1. Render должен стартовать без `TelegramConflictError`. Если конфликт есть, останови вторую копию бота или старый локальный запуск.
2. В логах должны появиться строки `RUNNER_THEME_APPLIED`, `PRO_FEATURES_V1_APPLIED`, `RUNNER_PRO_FEATURES_APPLIED`.
3. В Telegram отправь `/admin` и нажми `Синхронизировать`.
4. Проверь `/provider_health`: футбол/хоккей/теннис должны быть `OK`, `0 матчей` или понятная ошибка.
5. Открой Mini App через Telegram, не браузером. В профиле должна быть реферальная ссылка, баланс и текущий сезон.
6. Нажми прогноз в Mini App: должно открыться окно выбора суммы ставки.
